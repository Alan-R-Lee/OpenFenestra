## 已实现的体验

- 原生桌面继续显示未收纳图标；收纳项目由桥接逐项抑制绘制 / 输入，不移动源文件、不隐藏整个列表、不放到屏外。
- 分栏、多个标签页、单页时仍有添加按钮、高清 Shell 图标、搜索、普通分组与只读文件夹映射。
- 双击栏头折叠，单击展开；折叠提高透明度，展开恢复；设置中统一调整透明度。
- 登录自动运行、恢复布局并默认折叠，先显示分栏再等待 Shell。保存展开高度、位置、归属和分组顺序。
- 管理控制台有独立设置、侧栏选中态、红色移除按钮；顶部内容随滚动离开视口，给分组排序留空间。
- 我的分组拖动排序并保存，整理分栏遵循该顺序。拖放支持 Shell 虚拟项目与真实文件；返回桌面保护源文件，桌面外项目创建快捷方式。
- 原生控制器心跳、退出 / 崩溃恢复、桥接能力检查；跨虚拟桌面固定适配已实现，但实际切换仍待扩大验收。

具体协议和兼容边界见 [架构](ARCHITECTURE.md) 与 [验证](TESTING.md)，不能把上面的功能清单当作所有 Windows 构建均通过的保证。
