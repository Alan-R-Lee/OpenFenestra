WPF 冒烟测试使用独立临时数据目录和生成的示例文件，检查窗口显示、引用图标列表、折叠后高度恢复、标签页、文件夹监听、搜索、Win32 定位、布局保存与快照恢复。结果写入测试目录的 `smoke-result.json`。不触碰实际桌面文件。

## 需要更多设备验证

v0.2 的 `scripts/test-desktop.ps1` 会验证临时隐藏原生图标、收纳后去重、拖拽格式、放回桌面、原文件字节不变、关闭接管恢复，以及强制终止专用测试进程后的守护恢复。该测试需要交互式 Windows 会话，不在 GitHub 托管 runner 上接管桌面。

开机启动通过当前用户 Run 项实现；本机部署检查注册命令和应用重启恢复，不为了测试而重启用户电脑。便携模式默认不注册启动项，配置目录可由 `--portable`、`portable.mode` 或 `--data-dir` 选择。

- Windows 10 与 Windows 11 23H2、24H2 及后续版本。
- 多显示器正负坐标、100%/150%/200% 混合缩放、移除显示器。
- 实验桌面层下显示桌面、Explorer 重启、虚拟桌面、休眠恢复。
- OneDrive 按需文件、断开的网络盘、大型文件夹和失效快捷方式。
- 与 Fences 等现有桌面工具同时运行时的窗口层级。

首次验证已发现并修复：展开时 MinHeight 改变触发 SizeChanged，导致保存的展开高度被覆盖。回归测试直接检查折叠和展开后的实际 WPF 窗口高度。

v0.2 另修复了对子视觉对象的路由 DpiChanged 事件重建图标列表导致的循环；现在只在顶层 HWND 的 WM_DPICHANGED 后重新请求图标分辨率。回归测试不仅检查 Items.Count，还检查实际图标容器的高度与布局。

开发时可用 `--debug-windows` 临时把分栏和桌面图标层加入任务栏，便于窗口级 UI 自动化定位。正常运行不带该参数。
