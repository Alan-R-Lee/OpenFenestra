## 可重现命令

常规测试在 Windows 上运行，不向 Explorer 装入原生桥接：

```powershell
.\scripts\test.ps1
```

该脚本构建解决方案，执行 31 项 Core、20 项 Shell 数据测试和 26 项 WPF 冒烟检查。WPF 测试使用独立测试数据目录和生成的示例文件，结果写入该目录的 `smoke-result.json`。

Shell 数据测试也可独立执行；它是 STA Console 程序，不创建 UI：

```powershell
dotnet run --project tests/OpenFenestra.Shell.Tests -c Release
```

具备 MSVC x64 或 MinGW-w64 编译器时，构建并运行原生隔离验证：

```powershell
.\scripts\build-native.ps1 -SelfTest
```

该验证只把 DLL 装入自有测试进程，创建隐藏的标准及 `LVS_OWNERDATA` 控件和模拟 OLE 对象，不寻找或接入 Explorer。构建器检查 DLL 为 AMD64，并随输出收集所用工具链的运行时许可文件。

真实桌面测试需要完整原生 DLL 和交互式 Windows 11 x64 会话；以下命令会短暂连接当前 Explorer 的实际桌面，不作为普通托管 runner 的常规桌面测试：

```powershell
.\scripts\test-desktop.ps1
```

它使用独立测试布局，结果保存在测试数据目录的 `integration-result.json`、`integration-ready.json` 和崩溃后的检查 JSON。测试选择一个已有桌面快捷方式读取并比较字节，短暂改变其显示归属；不移动或删除原文件，不修改用户日常布局。崩溃检查终止的是专用测试控制器，不是 Explorer。

## 本轮检查详情

Core 回归新增了虚拟 Shell 项目的系统分类、大小写重复幂等、手工归属不变、清理多余桌面引用，以及映射页不独占文件的检查；其余覆盖路径校验、文件字节不变、布局限制、原子备份、损坏恢复与快照导出。

20 项 Shell 测试拒绝头部内偏移、溢出偏移、重叠 PIDL、过短 SHITEMID、缺少终止符、越界长度、截断头部、零子项、301 项和超过 4 MiB 的载荷；同时验证 300 项边界、无序但不重叠的偏移、私有格式、关闭 FileDrop、错误 CIDA 的普通文件回退、真实回收站身份、源流位置恢复及原文件字节不变。结构测试不把伪造 PIDL 交给原生 Shell。

WPF 冒烟检查真实项目容器的尺寸，防止只检查 Items.Count 却没有图标布局；还检查高分辨率 Shell 图标、折叠后更透明、展开恢复高度/透明度、目录监听、搜索、窗口定位、布局往返、快照和退出立即保存。

117 项原生隔离断言覆盖完整路径匹配、绘制结果、普通与批量选择、焦点/命中、外部 OLE 投递拒绝、合法位置转发、会话/协议拒绝、停用后重新接入，以及外部 OLE 目标替换后的停止抑制与保留外部注册。已隐藏图标仍保留其原生坐标；向这些旧坐标投递时拒绝操作，不能落入看不见的项目。模拟控件通过不代表所有 Explorer 构建及第三方 Shell 扩展都已通过。

真实 Explorer 的 10 项检查为：

1. 绘制、选择、输入和 OLE 能力全部就绪。
2. 原生图标列表保留原可见状态。
3. 不存在全屏桌面图标替代窗口。
4. 收纳指定项目后原生匹配数为 1。
5. 原 Shell 项目和原文件仍存在。
6. 内部拖拽载荷不提供源文件 FileDrop。
7. 返回桌面后移除分栏归属并恢复原生绘制。
8. 原快捷方式路径与字节不变。
9. 自动排列和网格设置保持原值。
10. 关闭整合后脱离组件，原生列表可见状态不变。

额外的崩溃检查在隐藏 1 个项目后强制结束控制器，确认桥接端点断开、隐藏计数为 0、原生桌面仍存在且列表可见状态与测试前一致。原生端每 500 ms 检查控制器进程；超过 8 秒无心跳也会恢复。真实进程退出恢复已通过；这不等于逐一验证了所有失联、系统挂起和消息线程阻塞情形。

## 已定位并修复的问题

本轮真实装入阶段发现，打包/MSIX 宿主中的 AppData 逻辑路径可能透明重定向，控制器读得到 DLL 并不表示未打包的 Explorer 能访问同一路径。现在对校验后的实际文件句柄调用 `GetFinalPathNameByHandle`，用底层实际路径建立线程 hook；没有为此放宽权限或修改系统安全策略。

真实身份重建阶段还发现，同步 `WM_COPYDATA` 输入回调直接调出 Shell COM 会触发 `RPC_E_CANTCALLOUT_ININPUTSYNCCALL`。现在只在回调中接收元数据并排队，待普通消息处理时解析 Shell 身份。此后真实 10 项整合与崩溃恢复检查通过。

其他回归保护包括：DLL 缓存 SHA-256/构建身份校验、关键 OLE 能力丢失时停止抑制、控制器会话与进程存活校验、清理时的 COM 重入保护，以及临时生成快捷方式后以禁止覆盖的操作提交。已有展开高度被 SizeChanged 覆盖、子元素路由 DPI 事件造成列表反复重建的问题继续由 WPF 冒烟检查覆盖。
