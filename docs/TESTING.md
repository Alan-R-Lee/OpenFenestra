# 验证范围

当前常规检查为 **40 项 Core、22 项 Shell 数据、34 项 WPF 冒烟**。原生组件另有 **117 项隔离断言**；2026-11-03 执行过 **12 项真实 Explorer 整合检查及 1 项控制器崩溃恢复检查**。历史真实桌面结果不能替代新 Windows 构建的兼容验收。

## 常规检查

```powershell
.\scripts\test.ps1
.\scripts\build-native.ps1 -SelfTest
```

| 层次 | 覆盖内容 | 是否接入真实 Explorer |
| --- | --- | --- |
| Core | 引用/分类、分组排序、路径与布局校验、原子保存、快照和版本迁移 | 否 |
| Shell 数据 | CIDA 偏移/边界检查、真实回收站 PIDL 往返、私有拖放格式和原文件字节保护 | 否 |
| WPF 冒烟 | 实际图标布局、高清图标、透明度、折叠/展开、标签、搜索、目录监听、列表排序、布局与退出保存 | 不装入桥接，仅检查窗口桌面宿主归属 |
| 原生隔离 | 自有普通/owner-data ListView 中的绘制、选择、焦点、命中、OLE、协议与清理 | 否 |

WPF 冒烟使用独立生成的样例文件和配置，产物写入被 Git 忽略的 `.qa`，包括结果 JSON 和界面预览。测试不会修改日常应用的布局。

原生隔离验证把 DLL 装入自有测试进程，创建模拟 OLE 对象和控件。通过这些断言，不代表全部 Explorer 版本和 Shell 扩展都兼容。

## 真实桌面检查

```powershell
.\scripts\test-desktop.ps1
```

这是交互桌面测试，需要 Windows 11 x64，运行前关闭其他 OpenFenestra 原生整合实例。脚本读取一个已有桌面快捷方式，短暂改变显示归属并比较原路径与字节；崩溃场景结束的是专用测试控制器，不是 Explorer。

已执行的检查覆盖：桥接能力就绪、原生列表可见状态保持、没有全屏替代层、指定项目的收纳和返回、原 Shell 项目/文件保留、原生排列标志不变、关闭后停止抑制，以及测试控制器异常退出后的恢复。本次还验证了取消/重新启用设置后的 PinView 状态读回；不将其视为实际虚拟桌面切换验收。期间 Explorer 未重启。

原生端每 500 ms 检查控制器，超过 8 秒无心跳也会停止抑制。真实进程退出恢复已验证；不能据此声称所有挂起或线程阻塞情形都已覆盖。

## 仍需交互验收

- 真实鼠标拖入/拖出、Esc 取消、拖到其他应用或任务栏，以及完整键盘选择/打开/删除组合。
- 外部文件返回桌面时同名快捷方式不覆盖，失效链接和按需文件的行为。
- Windows 虚拟桌面实际切换；PinView 成功返回不是切换验收。
- 重启后的登录时序、Explorer 重启、休眠/唤醒和长时间运行。
- 多屏、负坐标、混合 DPI、热插拔和其他桌面增强软件共存。

当前自启动已经通过登录任务手动触发验证；这不是重启后耗时保证。分组拖动的模型顺序、列表同步、保存及整理顺序已经自动验证，真实鼠标拖动仍需交互验证。
