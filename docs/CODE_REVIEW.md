# v0.3.8 代码核查与性能记录

日期：2026-11-03。范围覆盖 Core、WPF 控制台/分栏、Shell 与原生桥接、测试和构建/安装/CI 链路。采用源码审阅、定向回归和微基准；不把它视为所有 Windows 环境的正确性或安全性证明。

## 已处理

| 路径 | 问题与改动 |
| --- | --- |
| 批量收纳/返回 | 过去每处理一个项目就扫描所有普通页和额外桌面项目；现在用集合匹配，每批只扫描一次，保留输入顺序和映射页只读语义，容量检查仍在修改前执行 |
| 自动归类 | 已有归属用集合判重，分类目标用有序队列索引，直接追加新项目，避免反复对增长中的布局调用单项转移 |
| 文件夹元数据 | 复用目录枚举取得的属性；显示层复用已有 DesktopEntry，减少重复 Directory.Exists 查询 |
| 图标请求 | 直接异步投递 Shell STA，不再让线程池线程同步等待同一 STA；缓存命中直接返回，过期请求取消，FIFO 淘汰替代整表清空 |
| 折叠启动 | 展开前不枚举不可见项目或请求图标；保留原展开高度和正常展开后的内容 |
| 界面与桌面桥接 | 收纳集合未变化时不重复发送完整快照；同一 Dispatcher 周期的定位请求合并；启动状态短时缓存并在修改时失效 |
| 原生输入回调 | 修复选择时只遍历实际选择和焦点，不再对所有隐藏项目重复写状态；保留普通/owner-data 与 OLE 保护 |
| 拖放验证 | DragOver 只检查格式，Drop 才解析载荷；CIDA 按偏移排序并以相邻边界限制扫描，拒绝别名/重叠，避免重复扫描长 PIDL |
| 正确性与生命周期 | 虚拟身份使用严格 GUID 验证；释放 WindowsIdentity；清理失效窗口的固定状态；取消固定时实际调用 UnpinView 并读回验证 |

批量转移的主要扫描从 O(B × R) 降为期望 O(B + R)，B 是本批数量，R 是已有引用数。自动归类的索引构建和匹配对输入/已有分组进行线性遍历；Windows 文件查询时间另计。CIDA 的扫描受载荷长度限制，另有至多 301 个偏移的排序。

## 微基准

同一机器、Release 配置、相同临时基准程序；128 项预热，每项重复 3 次，取中位数。输入为合法的合成虚拟 Shell 身份，布局准备不计入。此数据不包含真实磁盘、图标提取或 Explorer COM I/O，也不是整机/UI 加速承诺。

| 操作 | 项目数 | 修改前 ms | 最终实现 ms |
| --- | ---: | ---: | ---: |
| 批量收纳 | 1,000 | 43.09 | 0.69 |
| 批量收纳 | 5,000 | 263.14 | 4.31 |
| 批量收纳 | 10,000 | 858.06 | 4.20 |
| 自动归类 | 1,000 | 28.70 | 0.86 |
| 自动归类 | 5,000 | 195.85 | 4.00 |
| 自动归类 | 10,000 | 818.15 | 3.54 |

批量结果的顺序、数量和桌面额外引用清理均在基准中核对；硬件调度、JIT 和 GC 会影响短任务时间。

## 验证与边界

40 项 Core、22 项 Shell、34 项 WPF 检查通过，构建无警告或错误；117 项原生隔离断言通过。真实 Explorer 的 12 项整合检查和专用控制器崩溃恢复通过；原路径、文件字节与桌面排列标志保持检查通过。

私有虚拟桌面接口、真实鼠标/键盘全流程、多屏混合 DPI、Explorer 重启及长期运行仍需按[验证范围](TESTING.md)扩展验收。文件夹/引用元数据读取仍是同步 I/O，巨大网络目录可能影响 UI；后续可采用有取消和并发上限的后台扫描。当前图标异步取消不能中断已进入第三方 Shell 提取器的一次调用。
