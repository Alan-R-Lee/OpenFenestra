# OpenFenestra 1.0.1

Windows 11 x64。源码及本机版本，尚未创建 GitHub Release。

## 改动

- 分栏文件拖出提供标准 FileDrop，支持接收文件的其他应用；保留桌面返回与 Esc 取消路径。
- 新增“最近”分栏，接收尚未归类的桌面项目，并提供一键归类；原文件位置保持不变。
- 隐藏图标的旧坐标改为向桌面背景投递，避免不可见文件夹截获文件，也避免直接拒绝投递。

## 验证与边界

44 Core、22 Shell 数据、36 WPF 冒烟检查与 119 原生隔离断言已通过。真实跨应用鼠标拖放仍需用户试用；虚拟 Shell 项目目前不支持跨应用拖出。

原生整合仍为实验性功能；收纳项目仍存在于 Explorer 列表中，网格占位、框选起点和背景菜单尚未实现完整空桌面行为。多屏、虚拟桌面切换及长期运行仍待扩大验收。

本轮同步源码至仓库；不创建版本标签或发布 GitHub Release。
