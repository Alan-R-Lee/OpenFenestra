# OpenFenestra 1.0.0

首个正式发布版。Windows 11 x64；应用与原生桌面组件源码采用 MIT，第三方材料按随包声明保留。

## 选择下载

- **Setup-Light-x64.exe**：约 3 MB，适合已安装 .NET 10 x64 Desktop Runtime 的电脑；缺少运行时时，向导提供 Microsoft 官方下载入口。
- **Setup-Offline-x64.exe**：约 50 MB，自带运行时，首次使用推荐。
- **OpenFenestra-win-x64.zip**：约 70 MB，完整解压即可使用，支持便携配置。
- **SHA256SUMS.txt**：以上三个文件的 SHA-256 值。

安装向导支持简体中文与英文、当前用户安装、开始菜单、可选桌面快捷方式及登录启动。卸载保留个人配置和原文件。程序尚未代码签名，请从本仓库下载并核对校验值。

## 主要功能

- 保留 Windows 原生桌面的透明分栏、标签页、搜索和高清 Shell 图标。
- 收纳后不重复显示原生图标，支持放回桌面；原文件保留。
- 折叠/展开、统一透明度、分组拖动排序与默认整理顺序。
- 自动保存、快照、导入导出、只读文件夹映射和登录折叠启动。
- 独立设置页面与托盘入口。

## 验证与兼容

40 项 Core、22 项 Shell、34 项 WPF 检查以及 117 项原生隔离断言已通过；真实桌面整合与控制器异常退出恢复也已验证。两种安装器已验证安装、应用载入、卸载及用户数据保留。

原生整合仍标为实验性功能，依赖部分非公开 Shell 接口。跨虚拟桌面真实切换、多屏混合 DPI、Explorer 重启与长期运行需要继续扩大验收；详见仓库验证说明。

本项目依赖使用人工智能开发，且为本开发者的第一个开源项目，欢迎感兴趣的贡献者提出意见及建议~
