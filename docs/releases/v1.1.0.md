# OpenFenestra 1.1.0

Windows 11 x64。发布日期：2026-11-23。

## 主要更新

- 分栏与折叠栏架采用半透明圆角细滚动条，移除浅色轨道和箭头，悬停、拖动时提亮，与桌面面板的整体风格保持一致。横向标签页使用同样的样式，滑块保留足够的拖动区域。
- 新安装软件创建的桌面快捷方式，以及桌面新增的文件、文件夹，稳定保留在“最近”。合并目录扫描和 Shell 快照，覆盖桌面更新延迟。
- 一键归类后展开目标分栏、切换标签页并高亮新图标。“最近”列出去向和数量，支持再次定位。
- 单击图标右键调用 Windows 原生经典菜单，双击右键打开 OpenFenestra 项目菜单。
- 默认按常用程度排序，可切换“新加入优先”或“原有顺序”。新图标显示“新增”标记，首次通过应用打开后取消；使用记录保存在本机。
- 每栏支持独立宽高、尺寸预设和拖拽缩放。设置中可选择自由排布、紧凑网格或折叠栏架，切回自由排布可恢复原布局。
- 从收起状态展开后，连续五秒无操作自动收起。输入会重新计时，菜单、编辑对话框和拖拽期间暂停；设置中可关闭。
- 修复屏外分栏启动恢复后再次消失的问题。

## 使用入口

- 分栏右上角“⋯ → 编辑分组”：设置独立宽高和尺寸预设。
- 管理窗口“设置 → 分栏排布”：选择排布方式及闲置收起开关。
- 分栏标签栏的排序按钮：切换图标排序方式。
- “最近”的“一键归类”：归类并查看图标去向。

## 验证与兼容范围

功能迭代已通过 56 项 Core、22 项 Shell 数据及 68 项 WPF 冒烟检查。包含自由布局恢复、栏架滚动、独立尺寸、使用记录保存，以及实际等待五秒后的收起验证。滚动条另通过 11 项专项检查，覆盖横竖拖动、轨道翻页、滚动至末尾及长列表最小滑块。本机更新检查确认原布局与设置保留。应用和两种安装器的文件版本均为 `1.1.0.0`，产品版本为 `1.1.0`。详细结果见[开发状态](../DEVELOPMENT_STATE.md)。

布局仍采用 v2，新增字段按默认值兼容旧配置。收纳与归类继续管理引用，更新时保留用户原文件及配置。

原生菜单采用 Windows 11“显示更多选项”对应的经典菜单。使用次数统计覆盖本应用发起且能识别的打开操作。

原生桌面整合仍为实验性功能。真实鼠标、多屏混合 DPI、栏架跨虚拟桌面和第三方菜单扩展仍需扩大交互验收；已收纳图标的原生网格占位问题仍在后续范围内。
