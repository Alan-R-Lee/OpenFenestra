# 使用指南

## 分组与桌面

创建分组后，将原生桌面图标拖入普通标签页。在“设置”中开启原生桌面整合，已收纳项目便不在原位置重复显示；文件仍留在原处，资源管理器的桌面文件夹仍能看到它们。

从分栏拖回空白桌面会解除归属。项目若来自桌面之外，会创建真实的桌面快捷方式，不移动原文件，也不覆盖同名快捷方式。

- 双击图标打开项目；右键可打开、定位或放回桌面。
- 拖动栏头移动分栏，拖动右下角调整大小。
- 双击栏头折叠，单击折叠栏头展开。
- `Ctrl+Alt+Space` 置顶速览所有分栏，再按一次恢复。
- 点击标签栏的 `+` 添加标签页；右键标签页编辑。
- 填写文件夹路径可创建只读映射页。它实时显示文件夹内容，不接受拖入或拖出。

## 管理控制台

“桌面分组”页面可以搜索分组、统一调整展开/折叠背景透明度，以及拖动卡片或左侧 `≡` 改变默认顺序。绿色线表示插入位置；顺序自动保存，点击“设置 → 整理分栏位置”后应用到桌面。上滑可让顶部介绍区域移出视野，为排序留出空间。

“布局快照”支持保存、恢复、导入和导出。恢复或导入前会自动备份当前布局。导出布局包含文件路径，分享前请检查。

“设置”集中管理原生桌面整合、登录自启动、跨虚拟桌面显示、自动归类，以及整理、折叠、展开和退出操作。跨虚拟桌面适配仍属实验性功能。

关闭控制台会收起到托盘，分栏继续运行。通过托盘或“设置 → 退出应用”正常退出，恢复 Windows 原生图标显示。

## 登录启动

开启后，应用优先使用当前用户的无附加延迟登录任务，以普通权限进入交互会话，不保存密码；策略不允许注册任务时使用 Run 项兼容方式。登录后分栏默认折叠，单击恢复原展开高度。

这是用户登录后启动，不是登录前运行的系统服务。Explorer 未就绪时会自动重试连接；实际时间取决于系统登录负载。

## 配置与便携模式

默认配置目录为 `%LOCALAPPDATA%\OpenFenestra`。控制台“使用指南”中可打开配置目录。

```powershell
# 将配置保存在程序旁的 data 文件夹
.\OpenFenestra.exe --portable

# 或在 EXE 旁创建 portable.mode 空文件后正常启动

# 使用指定目录
.\OpenFenestra.exe --data-dir "D:\OpenFenestra-Data"

# 后台启动到托盘
.\OpenFenestra.exe --tray
```

复制便携目录会保留配置；布局引用的外部文件仍使用原路径，换电脑后可能需要重新选择路径。打包宿主可能重定向 AppData，可用 `--data-dir` 明确位置。

## 更新、恢复与卸载

更新前通过托盘退出应用，再替换程序文件；保留 `data` 或原配置目录。可选[安装脚本](BUILDING.md#可选安装)会检查程序是否仍在运行。

关闭原生整合或正常退出会恢复原生图标。控制器失联时，原生组件会停止抑制图标；DLL 可能驻留到 Explorer 退出，但关闭功能后不再隐藏项目。

卸载前先在设置中关闭自启动，再退出并移除程序目录。配置、布局备份和原文件不需要随程序删除；日后重新安装可继续使用配置。
